# Global Godot Coordination Implementation Plan

> **REQUIRED SUB-SKILL:** Use the executing-plans skill to implement this plan task-by-task.

**Goal:** Enforce independent-project parallel Godot instances globally without import-cache races, excessive capture concurrency, focus theft, or interference with measurements.

**Architecture:** One standalone Python coordinator owned by this tracked fork, installed outside the skill at a content-addressed user-level location with a stable executable entry point. All project and asset callers use its shared state and admission protocol. No caller maintains a competing process-global singleton guard.

**Tech Stack:** Python standard library, POSIX process/locking primitives, existing Python/Node/shell launchers and installer.

## Contract

- Canonical project-folder identity: at most one admitted engine/import owner per folder; different worktrees and staged copies are independent.
- Ordinary headless work may run concurrently. Off-screen capture batches consume one of two machine-wide slots. Timing/performance/thermal measurements and active play take machine exclusivity.
- Exclusive waiters prevent starvation by closing new ordinary admission until earlier work drains. Admission is atomic across resources.
- Every launch participates in shared machine admission; engine existence alone is not a reason to reject other projects. Unmanaged engines require conservative ownership classification, never termination.
- Nested pipeline/launcher requests may reuse authenticated ancestor machine/capture admission; inherited text flags alone never confer ownership. Project ownership must not accidentally admit parallel sibling engines against one root. Reject unsupported nested upgrades rather than deadlock.
- Owner records include process identity, project, purpose and resource claims. Detect dead ownership without discarding a surviving owned engine; never signal a foreign job. Cancellation/timeout cleans only owned children and claims.
- Waiting, execution and owned cleanup fit one caller deadline. Clear blockers identify resource/project/owner rather than a generic engine-present error.
- Focus/parking, CHASE_MUTED=1, engine version pins, immutable artwork evidence and source hashes remain unchanged unless explicitly versioned.
